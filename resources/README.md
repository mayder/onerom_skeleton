# resources

Diretorio para imagens, fixtures e artefatos locais usados pela automacao.

Regras:

- nao armazenar credenciais, cookies, tokens ou dados reais de cliente;
- preferir arquivos anonimizados e pequenos;
- imagens usadas como locators devem ter referencia correspondente em `abstract/elements.py`;
- evidencias de execucao devem ir para `evidence/`, nao para `resources/`.
